# 棉花识别助手 Android 前端需求文档 v1.0

## 1. 项目概述

项目名称：棉花识别助手

项目目标：开发一款安卓 App，整体复刻现有鸿蒙端页面架构，并在安卓端进行适当体验优化。App 主要用于展示海关棉花相关新闻、查看棉花分类标准、上传或拍摄棉花图片进行智能识别，并提供账号登录、注册、识别记录、应用设置等功能。

推荐技术栈：

```text
React Native + Expo + TypeScript
```

最终交付目标：

```text
Android APK
Android 前端项目源码：apps/android
运行说明
接口配置说明
APK 打包说明
测试账号说明
```

开发周期：约 1 个月。若从 2026-05-27 开始，目标完成时间约为 2026-06-27。

## 2. 页面结构

App 使用底部四栏 Tab：

```text
前沿瞭望
分类标准
智能识别
我的信息
```

整体视觉风格复刻现有鸿蒙端：

```text
蓝色选中态
浅紫白背景
卡片式内容
中文为主，部分功能保留英文副标题
```

## 3. 前沿瞭望

功能范围：

```text
进入 App 后直接显示新闻列表
保留首页顶部棉花大图
支持搜索当前已加载新闻
不做新闻详情页
不做收藏功能
新闻接口不需要登录
```

新闻加载策略：

```text
优先显示本地缓存新闻
后台请求后端新闻接口刷新
后端不可用时使用前端 mock 数据兜底
不建议前端实时爬取新闻
```

## 4. 分类标准

功能范围：

```text
复刻现有鸿蒙端分类标准页面
内容直接写死在前端
不需要目录
支持上下滚动
分类标准可离线查看
```

已知内容：

```text
颜色分级
杂质分级
标准说明文字
标准图表
标准表格
```

实现建议：

```text
优先使用结构化文字 + 表格组件 + 局部图片
避免整页截图展示
保证文字清晰、可维护、可适配不同安卓屏幕
```

## 5. 智能识别

功能范围：

```text
支持调用系统相机拍照
支持从相册选择图片
一次只能选择一张图片
上传图片前不需要填写额外信息
未登录也可以识别
识别接口不强制 token
识别必须联网
```

建议流程：

```text
选择图片或拍照
预览图片
点击识别
显示上传中 / 识别中状态
后端返回结果
跳转识别结果页
展示原图和识别参数
```

结果页要求：

```text
必须显示用户上传的原图
展示后端返回的识别结果参数
识别失败时允许重新选择图片
```

## 6. 识别记录

功能范围：

```text
必须做识别记录
已登录时显示当前登录用户的识别历史
识别历史接口必须登录
支持删除识别记录
支持全选和批量删除 UI
不需要导出
不需要生成报告
不需要分享 PDF
```

未登录规则建议：

```text
未登录用户可以识别
未登录识别结果只保存在本机临时记录
登录后查看账号维度的后端历史记录
```

## 8. 后端接口要求

已确认：

```text
登录接口已完成
登录会返回 token
智能识别接口已完成
识别接口不强制登录
识别历史接口必须登录
新闻接口不需要登录
后端返回数据是统一格式
```

统一返回格式建议：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

建议接口清单：

```text
POST /auth/login
POST /auth/register
POST /auth/logout
POST /auth/change-password
GET  /news
POST /recognition
GET  /recognition/history
DELETE /recognition/history
GET  /user/profile
PUT  /user/profile
```
