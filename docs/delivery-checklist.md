## 四、现场注意事项

1. 手机与电脑必须连接**同一个 WiFi**；若企业网络启用了「客户端隔离」，手机将无法访问电脑（可改用手机热点）。
2. 电脑 IP 变化后**不需要重新出包**：在 App 的「系统设置 → 服务器地址」改一次即可。
3. 共用电脑：不修改网络配置、不改变防火墙开关；用完执行 `docker compose down` 释放资源（详见部署手册）。
4. 识别结果仅作辅助参考，不能替代人工检验或主管部门判定（已写入 App 内《用户协议》）。
5. 服务器上的数据（账号、识别记录）保存在该台电脑，更换电脑不会自动迁移；如需带数据请导出 MySQL 数据卷。
6. **目标部署机默认 Linux**：若现场只有 Windows 电脑才走备用方案；备用方案的模型服务是 conda 原生进程，**换机器必须在新机器上重建 conda 环境**（U 盘拷不过去），详见 `docs/deployment-guide.md` 附录 B。
7. **颜色级置信度怎么看**：它是模型对这张图颜色级的**把握程度**，不等于准确率，也没有「必须 >99%」的验收口径。修复预处理后（2026-09-20，`Resize(256)` 与训练一致），作者 75 张自测样本的**中位置信度约 80%**，约 1/4 样本低于 90%，属正常。现场若普遍低于 30%，先确认拍摄方式（棉样居中、深色底、尽量填满画面、光照稳定）与服务器地址是否指向本次部署；仍偏低则属模型能力问题，需**补数据重训**（依据与实测数据见 `docs/handoff.md` 第 20 节）。
